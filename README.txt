PROYECTO VELA - GITHUB PAGES

ARCHIVOS
- index.html: página y minijuego.
- assets/logo-vela.jpg: imagen del logo.
- QR-vela.png: QR que apunta a https://missaelperez.github.io/vela/

PUBLICAR
1. Abre https://github.com/missaelperez/vela
2. Selecciona Add file > Upload files.
3. Sube index.html, la carpeta assets (con logo-vela.jpg) y README.txt.
4. Pulsa Commit changes.
5. En Settings > Pages, elige Deploy from a branch, branch main, folder /(root), y Save.
6. Espera a que GitHub Pages publique la web en https://missaelperez.github.io/vela/

VIDEO
Para que el video se cargue desde el proyecto, coloca un archivo MP4 en la raíz del repositorio y nómbralo exactamente video-demo.mp4.
También puedes abrir la página, pegar en “URL del video” un enlace directo público a un archivo MP4 y pulsar “Cargar video”. Los enlaces de publicaciones de redes sociales normalmente no son enlaces directos al archivo.

NOTAS
- No se incluye video porque no se ha proporcionado uno.
- GitHub Pages sirve archivos estáticos; no necesita PHP ni base de datos.
- Antes de imprimir el QR, prueba la dirección publicada desde otro teléfono.
